# Command Registry

**IMPORTANT**: This registry strictly follows the definitions in `.essence/config/command-registry.yaml`. All command metadata and configurations are stored in that YAML file.

## Instructions for Registry
1. **Load Configuration**: Read and strictly follow all registry data from `.essence/config/command-registry.yaml`
2. **Apply Registry Settings**: Use command metadata, dependencies, and discovery patterns as defined
3. **Follow Structure**: Use registry structure and schema specified in the YAML
4. **Maintain Integrity**: Connect with all registered commands and maintain consistency
5. **Maintain Standards**: Use standard versioning, tagging, and dependency management as defined

## Configuration Reference
All detailed registry specifications are stored in `.essence/config/command-registry.yaml` including:
- Complete command catalog and metadata
- Command discovery and search patterns
- Dependency management and resolution
- Version tracking and migration paths
- Registry maintenance and health monitoring
- Registry API and management commands

For complete registry details, refer to `.essence/config/command-registry.yaml`

## Purpose
Central registry system for all Essence commands, agents, workflows, and expansion packs with metadata, dependencies, and discovery capabilities.
